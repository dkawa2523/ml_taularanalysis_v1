# [ISSUE] Template Taskチェック手順の適用範囲

- Status: 未決
- Related decisions: docs/issues/DECISIONS.md

## 背景

テンプレTaskの作成・確認手順を文書化したが、どのタイミングで誰が実施するかは未確定。
試験段階では運用を強制しないため、最小限のチェック運用を整理したい。

## 現象 / 期待

- 現象: チェックの実施頻度や責任範囲が曖昧
- 期待: 事故率を下げつつ、試験段階の負担を増やし過ぎない運用にしたい

## 影響範囲

- テンプレTaskの更新頻度と版管理
- 作成者/レビュー担当の責任分担
- UI上の運用オペレーション

## いまの暫定対応

- 重要なテンプレだけを手動でチェックし、結果は口頭ベース

## 恒久対応案（候補）

- 案A: テンプレ更新のたびに全チェックリストを実施する
- 案B: 重大変更のみフルチェック、軽微変更は簡易チェック
- 案C: 月次/四半期の定期監査でチェックをまとめて実施する

## 判定に必要な検証

- 手戻り/事故の発生率（チェック頻度との相関）
- チェックコスト（所要時間、担当者負荷）
- UI運用の属人性が下がるか
